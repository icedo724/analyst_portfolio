계약상 세부 수치·그래프는 공개할 수 없어, 방법론 중심으로 정리했다.

배경 및 문제 정의

(주)메디원은 수백 개의 병원·의원 거래처를 보유한 의료 분야 B2B 공급사다. 영업팀은 오랜 기간 담당자 경험에 기반해 거래처 등급을 부여해왔다.

두 가지 문제가 있었다.

  1. 재현 불가능성 — 같은 거래처를 두 영업 인력이 평가하면 등급이 달라진다.
  2. 신규 인력 의존성 — 경험이 없는 신입이 우선순위를 독립적으로 판단할 기준이 없어, 배정 후 일정 기간 동안 시니어의 안내에 의존해야 했다.

“등급 기준이 사람마다 다르면 CRM 데이터 자체를 신뢰할 수 없다.”

데이터

내부 데이터만으로는 거래처 속성을 설명할 수 없어, 공공데이터 4종을 결합해 내부 데이터를 보강했다.

구분 데이터 활용 목적
내부 거래처·매출·제품 데이터 등급 재구성의 기준 지표
외부 병원정보서비스 (건강보험심사평가원) 핵심 식별자(요양기호) 확보, 지역·종별 표준화
외부 의료기관별 상세정보 병상 수·전문의 수 등 규모 변수
외부 의료장비 상세 현황 + 의료기기 표준코드 비표준 장비명을 표준 분류 체계로 매핑

내부 거래처와 공공데이터 간 키가 없어 3단계 매칭을 설계했다: ① 거래처명 1:1 + 지역코드 일치 → ② 우편번호 반경 5km 후보군에 한글 유사도 매칭 → ③ 잔여 건 수동 확인.

분석 방법

1단계 — ABC 분석으로 기본 등급 구성

누적 매출 기여도 기준 상위 70% / 70~90% / 90~100% 세 구간으로 A/B/C를 부여했다.

2단계 — RFM으로 등급 세분화

  • Monetary는 ABC의 매출과 중복되어 제외
  • Frequency는 A·C등급에서 매출과 상관이 높아 제외하되, 상관이 약한 B등급에 한해 포함
  • Recency는 내부 도메인 지식으로 파악한 평균 거래 주기를 기준으로 세 구간 분할

최종적으로 A_안정 / A_우려 / B_안정 / B_우려 / C_신규 / 비활성의 6개 등급으로 재구성했다.

3단계 — 통계 검정

  • 분산분석(ANOVA) 으로 재구성된 등급 간 차이를 확인
  • 공공데이터로 보강한 거래처 속성(병상 수, 전문의 수, 보유 장비 등)을 후보 요인으로 두고 카이제곱 검정으로 등급과 유의하게 연관된 요인을 식별 — 일부 요인은 내부에서 경험적으로 인지하던 패턴과 일치함을 확인

핵심 결과

  • 요양기호 확보로 의료 공공데이터와의 상시 연동 체계를 구축 — 내부 데이터의 질적 향상과 지속적 최신화 가능
  • 직관 의존 등급을 재현 가능한 6등급 체계로 전환, 재산정 기준을 CRM에 반영해 신규 거래처도 동일 기준으로 자동 산정
  • 등급과 연관된 핵심 요인을 식별해, 신규 거래처의 향후 거래 규모를 가늠할 수 있는 기준 제시

회고

잘 된 점: 공공데이터 결합으로 내부 데이터만으로는 보이지 않던 거래처 속성을 확보했고, “직관을 크게 해치지 않으면서 기준을 명문화”하는 방향이 내부 수용도를 높였다.

한계: 매출 기반 지표만으로는 “성장 가능성 있는 신규 거래처”를 높게 평가하기 어렵다. 장기적으로는 거래처 생애 단계(신규/성장/성숙/이탈)를 추가 변수로 고려해야 한다.
